# Haroon Muneer Portfolio

Black and gold portfolio for a full stack WordPress developer.

- `static-site/`: finished HTML, CSS and JavaScript site (7 pages). Open `static-site/index.html`.
- `haroon-portfolio-theme/`: WordPress theme where every section is editable in Elementor. See its README for install steps.
- `haroon-portfolio-theme.zip`: the theme, ready to upload in WordPress.
